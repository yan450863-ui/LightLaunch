# 轻启 LightLaunch

面向 Windows 11 的轻量软件启动管理器。把便携软件和自制小工具放进统一目录，按分类查看、启动、停止和卸载。

**当前版本：0.1.10，早期公开版本。** 支持 Windows 11 x64，使用 .NET 8 Windows Forms。

![轻启首次打开的主界面](资料/界面/主界面.png)

## 下载与使用

从 [Releases](https://github.com/yan450863-ui/LightLaunch/releases/latest) 下载 `LightLaunch-0.1.10-win-x64.zip`，完整解压到可写目录，双击 `启动.cmd`。发布包自带 .NET 运行库，无需另外安装运行环境。GitHub 自动生成的 Source code 压缩包是源码，需要自行编译。

程序默认请求管理员权限，需在 Windows UAC 中确认；由管理器启动的工具会继承该权限。当前版本未进行代码签名。

首次打开选择自己的软件根目录，目录按下面的结构整理：

```text
我的软件库/
├─ 办公/
│  ├─ 编辑器/
│  │  └─ editor.exe
│  └─ 截图工具/
│     └─ capture.exe
└─ 自制工具/
   └─ 文件整理/
      └─ 启动.cmd
```

软件放入后自动出现，移出后从列表移除。发现新软件不会自动运行；多个入口时由你选择主程序并记住。

## 已有功能

- 分类、搜索、名称、图标、文件夹大小及运行状态。
- 启动 exe / cmd / bat，记住主入口、参数及软件目录内的工作目录。
- 优先跟踪由管理器启动的进程组；先正常退出，再确认是否强制结束。
- 打开软件文件夹；便携软件整个文件夹移入回收站；安装版匹配正规卸载程序。
- 卸载结束后检测残留，按软件保存记录。选择或搜索历史软件后自动重新检测，可查看并勾选删除候选。
- 文件残留移入回收站；注册表残留先按原 32/64 位视图备份，再在确认后删除。

## 使用边界

优先支持便携软件及自制小工具。完整剪切安装版目录后，部分软件能够关联原卸载登记，卸载期间临时提供原路径；服务、驱动、更新器或写死旧路径的软件可能无法迁移。管理员权限不能修复这些依赖，不建议直接搬动重要或复杂软件。

大小只统计软件文件夹。重启管理器不会接管之前的进程。残留检测只检查已知位置和精确名称候选，不代表全系统无残留；候选可能含个人配置或共享数据，删除前请核对。未确认完成卸载、位置变化、链接、公共目录或备份失败等情况会保留相关项。

配置、卸载记录及注册表清理备份保存在解压目录的 `数据/`。升级时退出程序，将新包的程序文件覆盖到原位置，保留 `数据/`。完整规则见程序内“使用说明”或 [使用说明](资料/使用说明.md)。

本版不含自动更新、软件商店、云同步、缓存清理或自动搬迁。

## 从源码构建

需要 Windows 和 .NET 8 或更新 SDK。工程保持现有中文目录结构，命令在仓库根目录运行：

```powershell
# 构建
dotnet build ./源码/LightLaunch/LightLaunch.csproj -c Release

# 运行 59 项使用模拟探针的残留检测检查，不修改系统文件或注册表
dotnet run --project ./测试/残留检测验证/ResidueChecks.csproj -c Release

# 生成自带运行库的 Windows x64 发布包、源码包及 SHA-256 校验文件
powershell -NoProfile -ExecutionPolicy Bypass -File ./源码/打包发布.ps1

# 检查发布包的实际程序集、内置说明、全新配置及主窗口
dotnet run --project ./测试/发布包验证/PackageChecks.csproj -c Release -- ./发布/0.1.10/LightLaunch-0.1.10-win-x64
```

发布产物位于 `发布/0.1.10/`，本地开发可用 `源码/构建.ps1` 生成依赖本机运行库的 `程序/`，然后双击根目录 `启动.cmd`。
