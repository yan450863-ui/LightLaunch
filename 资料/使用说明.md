# 轻启使用说明

## 添加与整理软件
完整包自带“软件文件夹”，首次打开默认读取它。每款软件保留整个文件夹放进去，单个 EXE 也可直接放入。每个完整文件夹或单 EXE 对应一款软件，内部的 app、data、runtime 不会单独列出。搬入后自动出现，移出后从列表移除，不会自动启动。
软件列表上方可切换“直接放软件”和“按分类放软件”。分类模式使用“根目录 / 分类 / 软件文件夹”，也支持分类目录内的单 EXE。旧配置保留原目录模式；旧版曾把软件拆成子文件夹时，请切换为“直接放软件”。可随时更换软件根目录。
左侧显示软件及其图标，右侧是所选软件的功能区。“重命名”只改显示名称，后面的“原名称”列保留原名，不修改实际文件或文件夹；中英文名称都能搜索。

## 启动与停止
选中软件后点击“启动”。优先推荐顶层唯一普通程序，卸载器和运行库辅助程序不会被自动选中。多个主程序时，在“设置入口”选择，也可用“浏览程序”手动指定软件文件夹内的 exe、cmd、bat。单 EXE 使用自身作为入口。图标读取主程序资源，没有图标时使用默认图标。
启动参数可以留空；工作目录填写软件文件夹内的相对路径，留空使用入口所在目录。
“停止”先请求正常退出，无法退出时才询问是否强制结束。管理器只优先跟踪本次由它启动的程序；重启管理器不会接管已有进程。

## 卸载软件
点击“卸载”后自动识别方式。便携工具将整个软件文件夹移入回收站，其中的配置和个人数据也会一起移走；安装版调用匹配的正规卸载程序。无法唯一匹配时需要手动核对。
单 EXE 显示“删除 EXE”，确认后只回收该文件，同目录的其他文件保持原样，不按整个软件库执行卸载或残留清理。
将安装版完整剪切到软件库后，部分软件可以关联原卸载记录，卸载时临时提供原路径。软件自身、更新器或服务依赖旧路径时可能无法正常工作，管理员权限不能修复所有路径依赖。

## 查看与删除残留
打开“残留记录”，选中或搜索软件后自动检测。检测结束后，勾选标为“可删除”的项目，或使用“全选可删除项”，再点击“删除所选”。删除前会显示完整位置并确认。
文件和文件夹移入回收站；注册表按原 32/64 位视图备份后删除。候选可能含个人配置或共享数据，请核对归属。“检查明细”是只读列表，不能勾选；返回普通列表后可以选择残留。
原登记或主程序仍存在时，项目显示“需先完成卸载”，不能当作残留删除。无法读取、链接、身份不符及系统公共位置也可能被保留，具体原因可悬停查看。
“显示已处理”可查看没有候选残留的历史记录。清理后自动检测并保存结果，软件文件夹消失后仍可管理残留。

## 数据与恢复
完整软件的大小只统计当前软件文件夹；单 EXE 只统计该文件。不包含外部配置和注册表。程序默认以管理员权限启动，需要时由 Windows 请求 UAC 确认。
配置及检测记录保存在项目的“数据”目录；注册表清理备份和恢复说明位于“数据 / 残留清理备份”。文件误删可从 Windows 回收站恢复；恢复注册表前请核对备份附带的原位置和视图说明。

## 从旧版升级
0.1.10 用户可下载小体积升级包，完整解压后双击“更新.cmd”，选择老版轻启主文件夹。更新前检查程序和运行库、正常关闭轻启并备份程序，失败时尝试恢复；用户软件、别名和配置均保留。备份位于原“数据 / 升级备份”，内含恢复说明。运行库不兼容时不修改老版，改用完整包覆盖程序并保留原软件和数据目录。
